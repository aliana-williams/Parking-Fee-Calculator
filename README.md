# Parking Fee Calculator

## Overview
This Python program calculates parking garage fees based on the number of hours parked. The application validates user input and applies minimum and maximum parking fee rules.

## Features
- Accepts user input for parking hours
- Calculates parking fees automatically
- Includes minimum and maximum fee limits
- Displays calculated parking cost

## Technologies Used
- Python

## How It Works
1. The user enters the number of hours parked.
2. The program validates the input.
3. Parking fees are calculated using hourly pricing rules.
4. Minimum and maximum fee limits are applied automatically.
5. The final fee is displayed to the user.
